# BrainSpark Arcade

Three short memory and thinking games for kids, each with Easy, Medium and Hard levels:

- **Logic Pairs**: flip cards to find twins (Easy) or things that go together, like 🐝 Bee + 🍯 Honey (Medium, Hard). Every card has a word label for reading practice.
- **Echo Beats**: watch and listen to the glowing pads, then tap the pattern back. Backwards Mode turns the pattern around.
- **Secret Code Jr.**: work out a hidden row of icons from clues. On Easy every guessed icon gets its own clue; Medium and Hard use classic count-only clues.

**Play:** open the site in Safari on an iPad, tap Share, then **Add to Home Screen**. It runs full screen and works offline.
Stars and best scores are saved on the device.

Everything lives in `index.html`. There are no build steps, trackers or outside requests, and the fonts are embedded.

Built with the help of AI (Gemini prototype, revised with Claude, Anthropic).
